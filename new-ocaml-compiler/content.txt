* `ocamlc` -- system program; OCaml source to bytecode
* `ocamlrun` -- system program; OCaml bytecode to syscalls
* `compile` -- Rocq code; OCaml source to bytecode
    * `lex-parse` -- Rocq code; OCaml source to AST
* `interpret-bytecode` -- Rocq code; OCaml bytecode to an interaction tree of syscalls
* `interpret` -- Rocq code; OCaml source to an interaction tree of syscalls
* `extract` : Rocq source -> OCaml source
* `process` : syscalls -> function

1. [Trusted] `interpret-bytecode` Write an AST + pretty-printer + interpreter for OCaml bytecode; ~150 instructions, ~1500 LoC  http://cadmium.x9c.fr/distrib/caml-instructions.pdf
    1. PBT harness to verify that `ocamlrun` and `interpret-bytecode` do the same thing
2. [Untrusted] `lex-parse` Process OCaml source into AST + [Trusted] `pretty-printer` reverse direction
3. [Untrusted] `compile` (using `lex-parse) and `interpret`
4. [Trusted] Define the compiler correctness theorem (`forall source, interpret(source) = (interpret-bytecode∘compile)(source)`)
    1. [Trusted-ish] Continue to prove theorem as `compile` / `interpret` evolve
    2. [RL] Impose a penalty for `interpret` length. Penalty is amplified if LLM cannot find a program (+ inputs to the program?) where the previous `interpret` and `ocamlrun∘ocamlc` disagree on behavior
5. [Trusted-ish] PBT that `ocamlc` and `compile` produce identical/equivalent(?) bytecode on a series of infinite families of syntax trees 
6. [Trusted-ish] To contribute to formal verification of Rocq: as each source file of Rocq comes into scope, we add Rocq source to the PBT on `ocaml` and `compile`
7. [Trusted-ish] To formally verify an OCaml compiler in OCaml: as the OCaml extraction comes into scope, require a proof that:
    1. `compile` and `process∘interpret∘extract(compile src)` behave the same
    2. Also `interpret-bytecode` and `process∘interpret∘extract(interpret-bytecode src)`
    3. Also `interpret` and `process∘interpret∘extract(interpret src)`
8. [Trusted-ish] To formally verify `ocamlc`: as `ocamlc` comes into scope, require a proof that `compile` and `process∘interpret(ocamlc src)` behave the same
9. Set up a Dockerfile and graders for all of these tasks, harden against exploits that involve modifying the testing infra
[Dates are for when the infrastructure/trusted parts for the task is finished, not the actual task]
