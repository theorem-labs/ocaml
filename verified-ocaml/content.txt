* `ocamlc` -- system program; OCaml source to bytecode
* `ocamlrun` -- system program; OCaml bytecode to syscalls
* `compile` -- Rocq code; OCaml source to bytecode
    * `lex-parse` -- Rocq code; OCaml source to AST
* `interpret-bytecode` -- Rocq code; OCaml bytecode to an interaction tree of syscalls
* `interpret` -- Rocq code; OCaml source to an interaction tree of syscalls
* `extract` : Rocq source -> OCaml source
* `process` : syscalls -> function

1. [Manual] `interpret-bytecode` Write an AST + pretty-printer + interpreter for OCaml bytecode; ~150 instructions, ~1500 LoC
    1. [Auto] PBT harness to verify that `ocamlrun` and `interpret-bytecode` do the same thing
2. [Auto] `lex-parse` Process OCaml source into AST + [Semi-auto] `pretty-printer` reverse direction
3. [Auto] `compile` (using `lex-parse) and [Auto] `interpret`
4. [Manual] Define the compiler correctness theorem (`forall source, interpret(source) = (interpret-bytecode∘compile)(source)`)
    1. [Auto] Continue to prove theorem as `compile` / `interpret` evolve
    2. [Semi-auto] Impose a penalty for `interpret` length. Penalty is amplified if LLM cannot find a program (+ inputs to the program?) where the previous `interpret` and `ocamlrun∘ocamlc` disagree on behavior
5. [Auto] PBT that `ocamlc` and `compile` produce identical/equivalent(?) bytecode on a series of [Manual] infinite families of syntax trees
6. [Auto] To contribute to formal verification of Rocq: as each source file of Rocq comes into scope, [Manual] we add Rocq source to the PBT on `ocaml` and `compile`
7. [Auto] To formally verify an OCaml compiler in OCaml: as the OCaml extraction comes into scope, [Manual] require a proof that:
    1. `compile` and `process∘interpret∘extract(compile src)` behave the same
    2. Also `interpret-bytecode` and `process∘interpret∘extract(interpret-bytecode src)`
    3. Also `interpret` and `process∘interpret∘extract(interpret src)`
8. [Auto] To formally verify `ocamlc`: as `ocamlc` comes into scope, [Manual] require a proof that `compile` and `process∘interpret(ocamlc src)` behave the same
9. [Manual] Set up a Dockerfile and graders for all of these tasks, harden against exploits that involve modifying the testing infra
